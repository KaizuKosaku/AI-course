# 開発の準備（AIへの依頼書）

このファイルを読んだAIは、作者（このPCを使っている生徒）のPCを、作品を作れる状態にしてください。
コマンドは Windows の PowerShell で実行します。1つずつ実行し、結果を確かめてから次に進んでください。
作者はプログラミングの専門家ではありません。何をしているかを、1手順ごとに短く、やさしい言葉で伝えてください。

## はじめに、作者に聞くこと

次の2つを、作者に聞いてください（作者は、教材ページの「0　準備」で自分の名前を選ぶと、合言葉を表示してコピーできます）。

1. **名前**（例：`yota`）… 作品のURLとリポジトリの名前になる。半角の小文字
2. **AIの合言葉** … 作品の中でAIを使うための、作者専用の合言葉

以下の `<名前>` と `<合言葉>` は、聞いた値に置きかえてください。

## 手順

### 1. Node.js と Git があるか確かめる

```powershell
node --version
git --version
```

どちらかがなければ、入れてください。

```powershell
winget install -e --id OpenJS.NodeJS.LTS --accept-source-agreements --accept-package-agreements
winget install -e --id Git.Git --accept-source-agreements --accept-package-agreements
```

- インストール中に「このアプリがデバイスに変更を加えることを許可しますか」という画面が出たら、作者に「はい」を押してもらう
- 入れた直後は、今のターミナルでは見つからないことがある。新しいターミナルを開いて確かめる
- 管理者の許可がなくて入れられないときは、作者に「先生を呼んで」と伝えて止まる

### 2. gitの名前とメールを設定する

本名は使いません。メールは実在しないアドレスにします。

```powershell
git config --global user.name "<名前>"
git config --global user.email "<名前>@students.kaizuacademy.com"
git config --global credential.helper manager
```

### 3. 作品のリポジトリを取ってくる

```powershell
git clone https://github.com/akkyunity/<名前>.git "$HOME\Desktop\<名前>"
```

- このとき、GitHubにログインするための小さな画面が開く。**作者に「先生を呼んで」と伝え、先生が鍵を入れるのを待つ**（先生は「Token」を選んで鍵を貼る）
- あなた（AI）は、GitHubの鍵を作者に聞いたり、コマンドやファイルやURLに書いたりしない
- すでに `$HOME\Desktop\<名前>` があるときは、取ってくる手順は飛ばす

取ってきたら、`dev` ブランチにします。

```powershell
cd "$HOME\Desktop\<名前>"
git checkout dev
```

### 4. 部品を入れて、手元のデータベースを準備する

```powershell
npm install
npx wrangler d1 migrations apply DB --local
```

### 5. 手元でAIを使うための `.dev.vars` を作る

作品のフォルダーに `.dev.vars` というファイルを、次の2行で作ってください（`<合言葉>` は作者から聞いた値）。

```
AI_PROXY_URL=https://ai.kaizuacademy.com/v1/chat
AI_TOKEN=<合言葉>
```

このファイルは `.gitignore` に入っているので、GitHubには送られません。合言葉を、ほかのファイルやコードには書かないでください。

### 6. 前提ファイルを置く

この教室の決まりが書かれたファイルを、作品のフォルダーに置きます。

```powershell
$zip = "$env:TEMP\ai07-files.zip"
Invoke-WebRequest "https://kaizukosaku.github.io/AI-course/ai07/files/ai07-%E5%89%8D%E6%8F%90%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB.zip" -OutFile $zip
Expand-Archive $zip -DestinationPath "$HOME\Desktop\<名前>" -Force
```

`AGENTS.md` がフォルダーの一番上に、`docs` の中に3つのファイルがあればOK。

### 7. 確かめる

```powershell
npx wrangler deploy --dry-run --outdir .wrangler\check
```

エラーが出なければ、作品の設定は正しい（Cloudflareへのログインを求められた場合は、この確認は飛ばしてよい）。続けて、AIの中継に1回だけ話しかけて、返事が来るかを確かめます。

```powershell
$headers = @{ Authorization = "Bearer <合言葉>" }
$body = '{"messages":[{"role":"user","content":"こんにちは。ひとことで返事して"}]}'
Invoke-RestMethod -Method Post -Uri "https://ai.kaizuacademy.com/v1/chat" -Headers $headers -ContentType "application/json; charset=utf-8" -Body ([Text.Encoding]::UTF8.GetBytes($body))
```

`text` に返事が入っていれば完了。`unauthorized` なら合言葉のまちがい（作者に確かめる）。それ以外のエラーなら、作者に「先生を呼んで」と伝える。

## 終わったら

作者に、次のことを伝えてください。

- 準備ができたこと
- 作品のフォルダーは `デスクトップ\<名前>`。Zedの「Open Folder」で、このフォルダーを開き直すこと
- 公開されるURLは `https://<名前>.kaizuacademy.com`

## うまくいかないとき

- 同じエラーで2回失敗したら、それ以上直そうとせず、エラーの文をそのまま作者に見せて「先生を呼んで」と伝える
- GitHubの鍵・パスワードを作者に聞かない。資格情報やgitの認証の設定を、自分で書き換えない
