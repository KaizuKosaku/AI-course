# ライブラリ・外部API・素材の選び方

決まった一覧から選ぶのではなく、**条件を満たすものなら使ってよい**。作者の理想に合うものを、広く探して選ぶ。

## ライブラリ

### 使ってよい条件

- 無料で、オープンソースである
- 広く使われていて、今も手入れされている
- 画面で使うものは CDN（`https://cdn.jsdelivr.net/npm/` など）から、サーバーで使うものは `npm install` で入れられる
- **バージョンを固定する**（例：`パッケージ名@1.2.3`。`@latest` は使わない）

使う前に、何を、なぜ使うのかを、作者に1〜2行で伝える。書き方は、そのライブラリの公式ドキュメントを確認してから書く。

### よく使われるものの例

これは例であり、ここにないものを使ってもよい。

| 用途 | 例 |
|---|---|
| 2Dゲーム | Phaser、PixiJS、Kaboom |
| 3D | Three.js、Babylon.js |
| 物理演算 | Matter.js、Rapier |
| アニメーション | GSAP |
| 音・音楽 | Tone.js、Howler.js |
| 手・顔・体の動きの認識 | MediaPipe（@mediapipe/tasks-vision） |
| 複数人での同時編集 | Yjs |
| 地図 | Leaflet |
| グラフ | Chart.js |
| 画面づくり | Preact、Alpine.js |
| サーバーの処理 | Hono |

## 無料の外部API・公開データ

### 使ってよい条件

- 無料で、登録やAPIキーがいらない
- 利用規約で、この使い方が許されている（出典の表示が必要なら、作品の中に表示する）
- 利用者の個人情報を送らない
- 回数の決まりを守る。同じデータを何度も取りに行かないように、サーバーやデータベースに一時的に保存する

登録やAPIキーが必要なサービスを使いたいときは、作者に「先生に相談して」と伝える。

### 例

これは例であり、条件を満たせばほかのものを使ってもよい。

| 用途 | 例 |
|---|---|
| 百科事典 | Wikipedia の API |
| 地図 | OpenStreetMap の地図（Leafletと組み合わせる。出典を表示する） |
| 天気 | Open-Meteo |
| 国・言葉・生き物などのデータ | 公開されているオープンデータ |

## 画像・音・フォントなどの素材

使ってよいのは、次のどれかに当てはまるもの。

- 作者が自分で作ったもの
- コードで作ったもの（図形、効果音の自動生成など）
- 無料の画像生成サービスで作ったもので、そのサービスの規約で公開に使ってよいもの
- ライセンスを確認した素材や、自由に使えるフォント（作った人の名前とライセンスが必要なら、作品の中に書く）

既存のゲーム・アニメ・キャラクターの画像や音楽、作品名は使わない。
