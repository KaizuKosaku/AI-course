# 公開前の安全チェック

作者に「公開前の点検をして」と頼まれたら、作品のすべてのファイルを読み、次の項目を1つずつ確かめる。
結果は「項目／OKかNGか／NGならその場所（ファイル名と行）と直し方」の表で作者に報告する。
**直すのは、作者が「直して」と言ってから。**

| # | 項目 | なぜ必要か |
|---|---|---|
| 1 | APIキー・合言葉・パスワードなどの秘密の値が、コードやドキュメントに入っていない | 盗まれると悪用される |
| 2 | 利用者が入力した文字を、`innerHTML` で画面に出していない | 他人の画面で悪いプログラムが動く（XSS） |
| 3 | AIに渡す利用者の入力で、AIへの指示を書き換えられない（「前の指示を無視して」などへの対策がある） | プロンプトインジェクション |
| 4 | 書き込み・投稿・AIの呼び出しに、回数の上限がある | 荒らし、AIの残高の消耗 |
| 5 | 本名・顔写真・学校名・住所などの個人情報が出ていない | 個人情報を守る |
| 6 | 他の人の作品（画像・音楽・キャラクター・作品名）を許可なく使っていない | 著作権 |
| 7 | 画像生成サービスで作った素材は、そのサービスの規約で公開に使ってよいものだけ | 規約違反 |
| 8 | 書き込みやチャットの機能があるなら、AIか先生のチェックが入る仕組みがある | いじめ・不適切な投稿 |
| 9 | AIを使う画面に「個人情報を書かないでね」という注意書きがある | AIの入力は外部のサーバーで処理される |
| 10 | 外部のAPIや公開データを使っているなら、規約どおりに使い、必要な出典を表示している。個人情報を送っていない | 規約違反・個人情報 |
| 11 | 遊び方・使い方と、作者のニックネームが画面のどこかに書いてある | 初めての人のため |
| 12 | エラーが起きたときに、真っ白にならず、わかりやすい表示が出る | 初めての人のため |
| 13 | スマホで開いたときに使える。PC向けの作品なら、少なくとも「PCで遊んでね」などの案内が出る | スマホで開く人が多い |
